# Web Visual Studio
Websites Project that i make for School tasks, and others.

## Important.
### How to run Websites in ProjectReact\...
1. you need to right click ProjectReact\music-list (if you want to run Music List)
2. then click *Open in Integrated Terminal*. the Terminal will open up and shows ...\Web-VS\ProjectReact\music-list>...
3. then you type `npm install` (If you First time run the Website)
4. if it already installed the type `npm run dev`, a link will show up
5. ctrl + click the link, the website now running.
6. Done.
